# Literature

Per-source notes on external sources—write one when a source needs a durable,
project-specific assessment. Each file distills one source: what it claims,
how it supports those claims, its scope and limitations, and its relevance
to this project. Cross-source synthesis belongs in `SURVEY.md`.

## Conventions

- Name each source note `<citekey>.md`, after its key in the project
  bibliography, `manuscript/references.bib`—shared across these notes,
  investigation reports, and the manuscript, and ideally generated by
  a reference manager.
- Never invent a citekey. If a source has no key yet, ask the researcher to
  add it to the reference manager.

## Template

The template does not need to be strictly followed. Add or remove sections
as required.

```markdown
# <!-- Title -->

**Reference:** <!-- Authors, venue, year. DOI or stable link. -->

## Summary

<!-- One-paragraph abstract of this file: the source, our assessment, its
     relevance. -->

## Detailed notes

<!-- The source as it presents itself: key results, claims, methods,
     derivations, and stated limitations—as long as needed. -->

## Assessment and relevance

<!-- Our assessment of the source, how it fits the wider picture, concerns,
     ambiguities, and its relevance to the project. -->
```
