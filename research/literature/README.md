# Literature

Notes should provide enough technical context to use a source's relevant
results without reopening the PDF. Preserve substance; compress prose.
Cross-source synthesis belongs in [SURVEY.md](../SURVEY.md).

Name notes `<citekey>.md` using the [bibliography](../../manuscript/references.bib).
Ask the researcher to add missing sources to the reference manager.
Keep local PDFs in `sources/`; they are untracked.

Organize each note around the source:

- **Reference:** authors, title, venue/year, DOI or stable link, and version.
- **Summary:** main contribution and scope.
- **Technical content:** setup, results, key reasoning, and limitations, with
  section/equation pointers for checking. Define symbols and conventions;
  state assumptions beside the results they qualify. Distinguish the source's
  results from our reformulations, inferences, and corrections.
- **Assessment:** brief, tentative relevance to this project. Keep project
  derivations and novelty claims in their own research records.

Use equations and short derivations where they carry the reasoning. Omit routine
algebra, peripheral applications, and procedural commentary unless they affect
interpretation. For acceptance, see [research guidance](../README.md#evidence-and-acceptance).
